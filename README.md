# 选题雷达

自媒体用的信息搜索工具（Vue 3 + TypeScript 前端，Node + Express + TypeScript 后端）。

## 一键生成（打开软件的默认页面）

填一个账号方向（比如「职场」「科技数码」，也可以不填），选写几篇、发到哪些平台，点「✦ 一键生成」：

1. 自动扫描 6 个平台的热榜，大约 120 条。
2. AI 挑出和题材相关、适合写的热点，会避开时政、灾难、未成年人隐私和时效太短的话题，并给每个热点定好切入角度和文章结构。
3. 一篇篇写好，放进「我的文章」。

每篇大约 30 秒到 1 分钟，中途可以停止，已经写好的会保留。文章写好后不会自动发出去：在「我的文章」里点开，右边是手机预览，检查后点「审核通过并发布」。

热榜、搜索、素材库、手动创作、定时任务这些页面收在顶部的「更多工具」里，需要时再打开。

## 更多工具

- **全网热榜**：微博、知乎、抖音、B站、百度、今日头条，6 个榜单放在同一个页面，可以按关键词筛选。缓存 5 分钟，点 ↻ 强制刷新。
- **关键词搜索**：同时搜 Bing 网页、搜狗微信公众号文章、B站视频。在热榜中点 ⌕ 就能直接搜这个热点。
- **素材库**：点 ☆ 收藏，可以写选题笔记、打标签、筛选。数据保存在 `data/favorites.json`。
- **AI 助手**：
  - 每条热点或搜索结果点 ✦：AI 用聊天的口吻告诉你这事值不值得写、最好的角度、5 个标题和要避开的雷区。看完觉得能写，点「去创作页写这篇」。
  - 热榜页点「AI 热榜总结」：像编辑在工作群里发消息一样，告诉你今天最值得写的 3-5 个选题。

## 创作（一页写完）

在热榜、搜索结果、素材库、监控提醒里点 ✍「写一篇」，或者直接打开「✍ 创作」页：

1. **写什么**：选题会自动带过来，也可以自己输入，再写几句你的想法给 AI 参考。
2. **怎么写**：
   - 文章结构：故事型、清单型、观点型、对比型、问答型、亲历型，或者自己写一个结构。
   - 文章类型：情感、温柔、治愈、幽默等，最多 3 个。
   - 发到哪里：第一个平台决定写作风格。
3. **生成**：AI 写完会自动变成一篇文章，进入编辑。
4. **编辑 + 手机预览**：左边编辑，右边是手机上的样子，可以切换成公众号、小红书、头条、知乎的样式，改一个字预览就跟着变。修改停下 2 秒后自动保存。
5. **发布**：发布前检查通过后，点「审核通过并发布」一步完成。

AI 写文章时会避开常见的 AI 套话（「值得注意的是」「总而言之」「赋能」「不仅……更是……」等），不用表格和分级标签，句子长短交错。你选的结构、类型和平台下次会自动带上。

## AI 设置

点右上角「⚙ AI 设置」，选一个服务商，填 API Key 就能用。支持所有兼容 OpenAI 接口格式的模型，预设了 DeepSeek、通义千问、Kimi、智谱 GLM。模型名会随平台更新而变化，以平台文档为准，可以手动修改。

API Key 保存在 `data/ai-config.json`，只有本机后端会读取，不会发给前端页面。

## 批量生成 Word 文档

在「素材库」点「📄 批量生成文档」，勾选要用的素材（一次最多 30 条），再点「下一步：生成文档」：

- 选择每条生成「选题分析」还是「文案初稿」。选初稿时，还可以选平台风格、文章结构和文章类型。
- AI 逐条生成，生成时会参考你在素材上写的笔记。生成过程在后台进行，可以关掉窗口，进度会保留。
- 生成好的 Word 文档：开头是标题和目录，之后每条素材单独一章，章首附上来源、链接、标签和笔记。某条生成失败不影响其他条，失败原因会写在对应那一章里。
- 文档保存在 `data/docs/`，在「历史文档」里可以重新下载。需要先配置 AI。

## 审核与发布

「发布」页列出所有文章。在「创作」页生成的文章会自动出现在这里，也可以点「新建」。编辑区和「创作」页一样，右边有手机预览。

1. **编辑**：修改标题、正文（Markdown，可以预览）、摘要、标签，上传封面图。
   - **平台专属版本**：编辑区上方每个选中的平台都有一个标签页。点「AI 改写成××版本」，AI 会按平台风格重写一份，比如把公众号长文改成小红书短笔记。也可以复制通用版本手动修改。有专属版本的平台发专属版本，没有的发通用版本。
   - **AI 校对**：找出错别字、病句、需要核实的说法，每条都可以单独「采用」或「忽略」。
   - **风格优化**：选择文章类型（情感、温柔、治愈、幽默、犀利等，最多 3 个，也可以自定义），AI 保留原文观点和事实，只调整语气和用词。结果先预览，点「采用」才替换正文。
   - **生成封面**：选尺寸（公众号 900×383、小红书 3:4、横版 16:9）、样式和配色，用标题文字直接生成封面图，不需要额外的 AI 绘图服务。
2. **审核**：编辑区下方的「发布前检查」会列出问题。必须修改的：标题超长、缺封面、还有【待补充】没填、小红书正文超过 1000 字等。提醒：广告法绝对化用语（「最好」「第一」等）、小红书站外引流词。必须修改的问题解决后才能点「审核通过」。审核通过后如果又改了内容，文章会自动退回「待审核」。
3. **发布**：勾选平台，点「发布到 N 个平台」。
   - **微信公众号**：通过官方接口推到草稿箱，不会直接群发。到公众号后台「内容管理 → 草稿箱」检查后自己发布。需要在「发布设置」里填 AppID 和 AppSecret，并在公众号后台把本机出口 IP 加进 IP 白名单。必须有封面图。个人订阅号或未认证账号可能没有草稿箱接口权限，可以先点「测试连接」检查。
   - **小红书、今日头条、知乎**：软件打开一个浏览器窗口，进入发布页，自动填好标题和正文（小红书还会上传封面作为笔记图片），然后停住，由你检查后亲手点「发布」。每个平台第一次需要在窗口里扫码登录，之后会记住登录状态，保存在 `data/browser-profile`。

软件不保存你的平台账号密码，也不会替你点「发布」按钮。平台改版后自动填写可能失效：找不到输入框时，会把正文复制到剪贴板，并提示你手动粘贴。

## 自动化

后端运行时（`npm run dev` 或 `npm start`）会定时执行下面这些任务，设置在「自动化」页：

- **热榜快照**：默认每 15 分钟记录一次 6 个热榜，保留最近 3 天，存在 `data/snapshots/`。
- **飙升标记**：和约 1 小时前的快照对比，在热榜上标出「新」（新上榜）和「↑N」（排名上升 N 位以上，N≥10）。点「只看新上榜/飙升」只显示这些。后端要先运行 1 小时左右才有对比数据。
- **热度走势**：热榜条目上点 📈，查看它近 3 天的排名变化。
- **关键词监控**：添加要盯的关键词，热榜标题命中就记一条提醒，右上角 🔔 显示未读数。可以选择自动存进素材库，也可以开启桌面通知（页面开着时生效）。
- **每日选题日报**：每天到设定时间，用 AI 生成选题日报，存在 `data/reports/`，可以在「自动化」页翻看历史。错过时间的话，后端启动后会补生成当天的日报。需要先配置 AI。

## 接入 MCP

热榜、搜索、素材库也可以作为 MCP 工具，在 Claude、Cursor、VS Code、Codex、Kiro 等 AI 工具里直接调用。配置方法见 [MCP.md](MCP.md)。

## 使用

开发模式（前端 http://localhost:5173 ，后端 8787 端口）：

```bash
npm run dev
```

打包后用一个端口运行（http://127.0.0.1:8787 ）：

```bash
npm run build
```

```bash
npm start
```

后端端口可以用环境变量 `API_PORT` 修改。

## 说明

数据来自各平台公开的网页接口，不是官方开放 API。如果平台调整了接口或开启风控，对应卡片会显示「加载失败」，其他来源不受影响。需要修改时，看 `server/hot.ts`（热榜）和 `server/search.ts`（搜索），每个来源都是一个独立对象。
